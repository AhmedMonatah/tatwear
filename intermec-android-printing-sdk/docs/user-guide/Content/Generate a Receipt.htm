Generate a Receipt

After you have followed Steps 1 through 5 of Basic Steps for Printing a Receipt, you can generate the receipt as follows:

  1. Change the font text style if desired.
  2. Write text to the printer and position the printhead.
  3. Print bar codes or bitmap files if desired.
